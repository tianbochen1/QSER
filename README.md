# Quantile series and quantile-crossing processes

Companion repository for **Quantile Series: Finite-Sample Structure and Asymptotic Links to Quantile-Crossing Processes**, by Tianbo Chen, School of Big Data and Statistics, Anhui University.

## Paper

Quantile series (QSER) reconstruct a time-domain sequence from the complex coefficients underlying a coefficient-based quantile periodogram (QP). Their ordinary periodograms equal QP. The paper studies exact finite-sample identities, the information retained under marginal transformations, and asymptotic connections with scaled quantile-crossing processes. It develops reconstruction bounds, Fourier limits, marginal identification results, and consistency results for spectral summaries under stated conditions.

The information comparison concerns marginal location and amplitude. QSER and crossing processes share the same normalized population spectral target. Independent-record periodogram averaging separates sampling variation from finite-record bias and does not, by itself, establish an information ordering.

The numerical study includes processes with the same ordinary spectrum and different tail spectra. The application compares QSER and crossing representations of eyes-open and eyes-closed EEG recordings.

The included computational scripts reproduce the averaged-periodogram and paired scale experiments. The saved summaries are the numerical outputs used for those experiments in the manuscript. Replicate-level periodograms are generated by the R script and are not tracked in the repository.

## Running the experiments

The calculations require R with `quantreg` and Python with the packages listed in `requirements.txt`. The R package `parallel` is distributed with R. Run the following commands from the repository root:

```sh
Rscript -e 'install.packages("quantreg", repos="https://cloud.r-project.org")'
python -m pip install -r requirements.txt
Rscript scripts/ensemble.R
python scripts/process_ensemble.py
```

The R script writes replicate-level periodograms to `results/ensemble/`. The Python script updates the summaries in that directory and writes `qser_ensemble_spectra.pdf` and `qser_scale_averaging.pdf` to `figures/`. Paths are resolved from the script locations. Numerical settings are specified in the scripts. Individual records use deterministic seeds. On Windows, the R calculation runs sequentially.

## Experimental targets

The two-state volatility model has a common Gaussian-mixture marginal distribution and unit ordinary spectrum. Its quantile spectrum is available analytically. The scaled crossing comparator uses the population density so that reconstruction error is separated from density estimation. The scale comparison pairs each record with twice that record; the crossing arrays agree, and QP scales by four. Averaging is performed across independent records without frequency smoothing.

The saved errors cover both sample sizes, both persistence settings, and all three quantile levels. Crossing estimates can have smaller errors after averaging because finite-record QP bias remains. The paper reports this behavior alongside the amplitude-information comparison.

## EEG data

The EEG Motor Movement/Imagery Dataset is available from [PhysioNet](https://doi.org/10.13026/C28G6P). The manuscript uses participant S001, baseline records R01 and R02, and channel O1. EEG recordings are obtained from the original provider and are not redistributed here.
